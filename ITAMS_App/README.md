## IT ASSET MANAGEMENT SYSTEM (ITAMS)

# Thanh Dang

# A web application build with ASP.NET Core and Razor Pages to manage IT assets, employees, software licenses, maintenance records, and administrators with role-based access. 

# Features:
Assets: Add, edit, view details, and organize IT assets by type and status.

Employees: Track employees and assign them assets.

Maintenance Records: Record maintenance history and link them to specific assets.

Software Licenses: Manage software license keys and their expiration dates.

Administrators: Role-based administrator panel with permission levels: FullAccess, IT, HR, License.

Relational Database: Connected to SQL Server with Entity Framework Core using Code First Migrations.

Validation & Error Handling: Input validation, dropdown selections, and error feedback.

# Using:
ASP.NET Core Razor Pages
C#
Entity Framework Core
SQL Server
HTML/CSS
JavaScript
Visual Studio Code

# Folder Structure
/Pages: Razor Pages for CRUD operations
/Model: Data models
